# Cards de estudo

Para qualquer trabalho de análise dos cadernos Goodnotes, criação/atualização de
cards ou preparação de automações de revisão, leia primeiro
`cards-estudo/AGENTS.md`, `cards-estudo/README.md` e
`cards-estudo/estado/cursor.json`.

O início autorizado de **Problemas é a página 45, inclusive**. Não processe as
páginas 1–44 para criar cards. A página mostrada pelo visualizador não é o cursor
de trabalho concluído. Não reinicie nem sobrescreva um cursor existente.
